Pipeline High-Level Flow

This section explains the end-to-end journey of a video frame in main.py. The system transforms raw pixel data from multiple asynchronous streams into a unified identity graph using a "Tracking-by-Detection" paradigm optimized for cross-camera consistency.

1

Per-Camera Isolation

Each stream utilizes its own YOLO and ByteTrack instance. This prevents coordinate-frame pollution and ensures stable Kalman filter predictions.

2

Quality Gating

Raw detections are filtered via Laplacian variance (blur) and aspect ratio checks. Only high-fidelity crops populate the identity gallery.

3

Deep Feature Extraction

OSNet generates 512-dim embeddings. Simultaneously, HSV histograms capture clothing color signatures as a pose-invariant fallback.

4

Intra-Camera Linking

New tracks are compared against recently lost tracks in the same camera to handle occlusion-induced ID jumps.

5

Cross-Camera Association

Every MATCH_INTERVAL, the Hungarian Algorithm solves the global assignment problem across all camera pairs.

6

Global Fusion

Union-Find (DSU) manages the global identity graph, freezing visual labels for display stability even if logical merges happen later.

The Processing Engine

Data integrity starts at the crop level. main.py implements rigorous quality gates to ensure the Re-ID gallery isn't polluted by motion blur, partial detections, or poor lighting.

⚡ Pre-processing Logic

  • 1. CLAHE Normalization: Applied in LAB space to the L-channel. This compensates for exposure differences between indoor and window-adjacent cameras.
  • 2. Blur Gating: Calculated via Laplacian Variance. Threshold set at 45.0. Lower values signify motion blur, which smears pixel gradients and destroys ReID signal.
  • 3. Geometric Filtering: Rejects crops with area < 1500px or aspect ratios outside [1.2, 4.5] to filter out partial bodies or background noise.

Feature Fusion Strategy

The "Identity Signature" is a weighted ensemble of two distinct biometric signals. This dual-signal approach ensures robustness against viewpoint changes where deep features might fail but color consistency remains high.

Deep Embedding (75%)

Extracted via OSNet_x1_0. This 512-dimension vector captures architectural body features and clothing patterns. L2-normalized for Cosine Similarity.

HSV Histogram (25%)

A 2D (H, S) histogram of the CLAHE-normalized crop. While OSNet handles "what" the clothing looks like, the histogram handles the "distribution of colors," providing stability in poor lighting.

Union-Find Logic

The UnionFind class manages identity clusters. It uses Path Compression for O(α(n)) efficiency. Crucially, visual stability is maintained via the Frozen Display ID: once an ID is shown to the user, it is locked even if the back-end graph merges it into a larger cluster later.

Track Gallery (Top-K)

Instead of a moving average, TrackGallery stores the 5 highest-quality crops (by score). The representative embedding is the centroid of these top crops, ensuring one "bad frame" (like a person walking away) doesn't pollute the profile.

# Multi-Camera Person Re-Identification — Project Structure

## Folder layout

```
reid_project/
├── config.py                    # ALL shared settings — paths, thresholds, camera list
├── requirements.txt
├── detection/
│   └── detect_and_track.py      # YOLOv8 + ByteTrack, saves crops per track ID  [Person A]
├── reid/
│   └── extract_features.py      # pretrained OSNet embeddings + temporal averaging [Person B]
├── matching/
│   └── identity_manager.py      # cosine similarity matching + TTL cleanup [Person B]
├── calibration/                 # homography setup (stretch goal, Saturday)
├── dashboard/
│   └── app.py                   # Streamlit UI [Person B]
├── data/
│   ├── videos/                  # put cam1.mp4, cam2.mp4 here
│   ├── crops/                   # auto-generated by detection/
│   ├── embeddings/              # optional cache
│   └── annotated/               # auto-generated annotated output videos
└── docs/                        # write-up, architecture diagram, results
```

## Pipeline order (build in this sequence)

1. **detection/detect_and_track.py** — run on each camera's video, confirms boxes + track IDs + crops.
2. **reid/extract_features.py** — turns crops into embeddings, averages over a track's recent frames.
3. **matching/identity_manager.py** — takes (camera_id, track_id, embedding, timestamp) from step 2 for every camera, decides same-person vs new-person, handles 10s TTL release.
4. **dashboard/app.py** — visualizes camera feeds with global ID overlays.

## Division of work

- **Person A**: detection/, reid/ (steps 1-2 — everything that turns raw video into embeddings)
- **Person B**: matching/, dashboard/ (steps 3-4 — everything that turns embeddings into a usable system)

## Do we train any models?

No. Everything uses pretrained weights:
- YOLOv8n — pretrained on COCO, detects "person" out of the box.
- ByteTrack — an algorithm, not a trained model.
- OSNet (torchreid) — pretrained on Market-1501, used as-is.

The only "tuning" is adjusting `SIMILARITY_THRESHOLD` in `config.py` empirically against your own test footage (Saturday).

## How to run each piece standalone (for testing before integration)

```bash
# Step 1: detection + tracking
python detection/detect_and_track.py --source data/videos/cam1.mp4 --cam_id cam1 --show

# Step 4 (once built): dashboard
streamlit run dashboard/app.py
```
